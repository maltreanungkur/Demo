## Problem

This is an interesting question from my BMath Ring Theory course, which was taught by <a href="https://www.isibang.ac.in/~sury/" target="_blank">Prof. B. Sury</a>. The course had way too many interesting problems and clever ideas, tbh some of them are really wild ones, but this question is special, beacuse you can explain it to even high schoolers, and yet, the solution is super slick! Thanks again to Prof. B. Sury for sharing this in class.  

\\( \textbf{Question:} \\) Let \\( f \in \mathbb{Z}[x] \\) be a polynomial of degree \\( n > 0 \\). Pick \\( n+1 \\) distinct prime numbers, say \\( p_1, \dots, p_{n+1}\\). Show that there exists a polynomial \\( g \in \mathbb{Z}[x] \\) such that  

\\[
fg = \\sum\\limits_{i=1}^{n+1} c_i x^{p_i}  \quad \text{for }c_i \text{ in } \mathbb{Z}
\\]

I hope that the problem statement is clear! Please give it a honest try, and once you are done, the solution is all yours!  

---  

### Solution  

Alright, so what’s the trick? The first thing to notice is that the specific prime numbers \\( \\{ p_1, \\dots, p_{n+1} \\} \\) don’t actually matter; they’re just there to distract you! The statement holds for any \\( n+1 \\) distinct numbers, so don’t overthink about those primes. 

The way to attack this problem is to consider the quotient ring:  

\\[
R = \\mathbb{Q}[x] \\big/ (f)
\\]

where \\( (f) \\) is the ideal generated by \\( f \\). Why are we looking at this? Because \\( R \\) is a \\( \\mathbb{Q} \\)-vector space! (That’s why we take \\( \\mathbb{Q} \\) if we worked over \\( \\mathbb{Z} \\), we wouldn’t get a vector space, and things would be messier, if we bring modules etc.)  

Now, since \\( f \\) has degree \\( n \\), the space \\( R \\) has dimension \\( n \\). The reason for that is simple: any power of \\( x \\) that’s \\( \\geq n \\) can be rewritten in terms of smaller powers, using the fact that we’re in \\( R \\), and that we have in some sense an "extra" zero, namely \\( f \\), a polynomial of degree \\( n \\). So eventually, any polynomial in \\( \\mathbb{Q}[x] \\) reduces to a polynomial of degree at the most \\( n \\) in \\( R \\).  

Thus, a natural basis for \\( R \\) is \\( \\{ \\overline{1}, \\overline{x}, \\dots, \\overline{x^{n-1}} \\} \\). Now, look at the set \\( \\{ \\overline{x^{p_1}}, \\overline{x^{p_2}}, \\dots, \\overline{x^{p_{n+1}}} \\} \\), this is an \\( n+1 \\) element set inside an \\( n \\)-dimensional vector space, that's one more than the \\( \\dim R \\), so it *has* to be linearly dependent set! That means there exist some \\( u_i \\in \\mathbb{Q} \\) such that  

\\[
\\sum\\limits_{i=1}^{n+1} u_i \\overline{x^{p_i}} = 0 \\quad \\text{in } R,
\\]

\\[
\\implies \\sum\\limits_{i=1}^{n+1} u_i \\overline{x^{p_i}} = \\overline{0}.
\\]

But what does that actually mean? Well, if we lift the equation we got in \\(R\\) to \\( \\mathbb{Q}[x] \\), we get that there's some polynomial \\( g \\in \\mathbb{Q}[x] \\) such that  

\\[
\\sum\\limits_{i=1}^{n+1} u_i x^{p_i} = f g.
\\]

Now, there’s just one last detail: we need to make sure everything is in \\( \\mathbb{Z}[x] \\). To do that, just multiply through by the least common multiple of the denominators of the coefficients of \\( g \\) and \\(u_i\\), and boom we get:

\\[
fg = \\sum\\limits_{i=1}^{n+1} c_i x^{p_i},
\\]

for some integers \\( c_i \\). And that’s it! A super clean solution, but the trick is sneaky. Hope you enjoyed this one! See you in my next post! Bye :)

\\[

So $\\Phi$ is indeed a homomorphism.
Now, to make any further progress, we need few lemma which is of extreme importance in Algebraic Topology.
\\begin{proposition}
Given any space $Y$, a map $F: Y \\times I \\to S^1$, and a map $\\tilde{F}: Y \\times \\{0\\} \\to \\mathbb{R}$ which lifts $F|_{Y \\times \\{0\\}}$, there exists a unique map $G: Y \\times I \\to \\mathbb{R}$ which lifts $F$ and is an extension of $\\tilde{F}$.
\\end{proposition}
Before going into the proof of this proposition, we consider two lemmas which are worth noticing and are direct consequence of the above proposition.


\\begin{lemma}[The Path Lifting Property]\\label{lemma: The Path Lifting Property}
For each path \\( f: I \\to S^1 \\), with \\( f(0) = x_0 \\) and for each \\( \\tilde{x}_0 \\in p^{-1}(x_0) \\), there is a unique lift \\( \\tilde{f}: I \\to \\mathbb{R} \\) such that \\( \\tilde{f}(0) = \\tilde{x}_0 \\).
\\end{lemma}

In the above lemma, $p^{-1}(x)$ is the pullback of $x$ under the map $p$ (the projection map from $\\RR$ to $S^1$).

\\begin{lemma}[The Homotopy Lifting Property]\\label{lemma: SpCase Path}
For each homotopy $f_t: I \\to S^1$ of paths starting at $f_t(0) = x_0$ and for each $\\tilde{x}_0 \\in p^{-1}(x_0)$, there is a unique lift $\\tilde{f}_t: I \\to \\mathbb{R}$ such that $\\tilde{f}_t(0) = \\tilde{x}_0$.
\\end{lemma}

Notice that Lemma \\ref{lemma: The Path Lifting Property} and Lemma \\ref{lemma: SpCase Path} are the special cases when $Y = \\{y_0\\}$ is a single point and $Y = I$ is the unit interval (pictured in next page), respectively.










We will not prove Lemma \\ref{lemma: The Path Lifting Property} and Lemma \\ref{lemma: SpCase Path} now, but rather use them to prove $\\Phi$ is a bijection, and in order to do so, we will first prove that $\\Phi$ is a surjection and then we will prove $\\Phi$ is an injection. In order to prove that $\\Phi$ is a surjection, we will use Lemma \\ref{lemma: The Path Lifting Property}.

But, let's recall Lemma \\ref{lemma: The Path Lifting Property} once:

\\begin{lemma}[The Path Lifting Property]
For each path \\( f: I \\to S^1 \\), with \\( f(0) = x_0 \\) and for each \\( \\tilde{x}_0 \\in p^{-1}(x_0) \\), there is a unique lift \\( \\tilde{f}: I \\to \\mathbb{R} \\) such that \\( \\tilde{f}(0) = \\tilde{x}_0 \\).
\\end{lemma}

It's easy to see that a path in the helix (\\( \\mathbb{R} \\)) will project down to a path in \\( S^1 \\) (we've already used this idea in proving $\\Phi$ is a homomorphism). Lemma \\ref{lemma: The Path Lifting Property} tells us that the converse is true too! That is, given a path \\( f \\) ``downstairs'' in \\( S^1 \\) that starts at \\( x_0 \\), and given a lift \\( \\tilde{x}_0 \\) of \\( x_0 \\), there is a path \\( \\tilde{f} \\) ``upstairs'' in \\( \\mathbb{R} \\) starting at \\( \\tilde{x}_0 \\) that projects down to \\( f \\).

Notice the set \\( p^{-1}(x_0) \\) is infinite! So the lemma says that if you fix an \\( \\tilde{x}_0 \\in p^{-1}(x_0) \\) (we call this a point in the ``fiber" above \\( x_0 \\)), then there is a map \\( \\tilde{f}: I \\to \\mathbb{R} \\) which takes \\( 0 \\) to \\( \\tilde{x}_0 \\).

We will now proceed to show \\( \\Phi \\) is surjective.

Let \\( [f] \\in \\pi_1(S^1) \\) be the path-homotopy class of some loop in \\( S^1 \\) and pick a representative \\( f: I \\to S^1 \\) with base point \\( (1, 0) = f(0) = f(1) \\). We wish to show that there is an \\( n \\in \\mathbb{Z} \\) such that \\( \\Phi(n) = [f] \\), i.e., such that \\( f \\sim \\omega_n \\) for some \\( n \\).

To this end, begin by observing that \\( 0 \\in p^{-1}((1,0)) = \\mathbb{Z} \\). Hence by Lemma \\ref{lemma: The Path Lifting Property}, there is a unique lift \\( \\tilde{f}: I \\to \\mathbb{R} \\) such that \\( \\tilde{f}(0) = 0 \\). Now, since: \\[ (p \\circ \\tilde{f})(1) = f(1) = (1, 0) \\in S^1, \\]
we see that \\( \\tilde{f}(1) \\) must be an integer, well that's because $p : I \\to S^1$ is defined by \\( s \\mapsto (\\cos(2\\pi s), \\sin(2\\pi s))\\) has the property that it outputs $(1,0)$ iff $s \\in \\ZZ$ (here $s=\\tilde{f}(1)$). In other words, \\( \\tilde{f} \\) is a path from \\( 0 \\) to \\( n \\) for some integer \\( n \\) (in the picture below, \\( \\tilde{f} \\) is the red path and \\( n = 3 \\)).

\\[

\\]
via the homotopy $p \\circ F$, with this, we conclude \\( [f] = [\\omega_n] = \\Phi(n) \\), and thus \\( \\Phi \\) is surjective. Now, we will use Lemma \\ref{lemma: SpCase Path} and will show $\\Phi$ is one-to-one.

\\end{lemma}

Now, we will go ahead and using Lemma \\ref{lemma: SpCase Path}, we will be proving that $\\Phi$ is an injection.
To be careful, we should emphasize that $f_t$ isn't merely a homotopy, it is a path homotopy, i.e. it is a homotopy between two paths $f$ and $g$ that share the same initial point, $x_0$ (this is what we mean by $f_t(0) = x_0$) and ending point.

We are fixing $t$ here (just momentarily) and are imagining that $f_t: I \\to S^1$ is just a path, much like the path $f$ in Lemma \\ref{lemma: The Path Lifting Property}. But in the back of our mind, we know that the statement of Lemma \\ref{lemma: SpCase Path} holds for all $t \\in [0, 1]$ and hence for the family of maps -- i.e. the homotopy -- $f_t$.

\\begin{doubt}
    Is it correct to see Lemma \\ref{lemma: The Path Lifting Property} as a special case of \\ref{lemma: SpCase Path}?
\\end{doubt}

It's easy to see that a homotopy in the helix ($\\mathbb{R}$) will project down to a homotopy in $S^1$. This lemma tells us that the converse is true too! That is, given a homotopy in $S^1$ of paths that start at $x_0$, you can find a lifted homotopy of paths in $\\mathbb{R}$ that start at the lift of $x_0$.

Suppose $\\Phi(m) = \\Phi(n)$ so that $\\omega_m \\sim \\omega_n$, for some $m, n \\in \\mathbb{Z}$. We wish to show $m = n$. Let $f_t: I \\to S^1$ be the homotopy from $\\omega_m$ to $\\omega_n$ with $f_0 = \\omega_m$ and $f_1 = $\\omega_n$, and notice that $f_t(0) = (1, 0) \\in S^1$. This follows since $(1, 0)$ is the common starting point of $\\omega_m$ and $\\omega_n$ (i.e. $\\omega_m(0) = \\omega_n(0) = (1, 0)$). Also note that $0 \\in p^{-1}(1, 0) = \\mathbb{Z}$.

By Lemma \\ref{lemma: SpCase Path}, there exists a unique lift $\\tilde{f}_t: I \\to \\mathbb{R}$ such that $\\tilde{f}_t(0) = 0 \\in \\mathbb{R}$. Moreover, since the lift $\\tilde{f}_t$ is unique, we must have    
$\\tilde{f}_0 = \\tilde{\\omega}_m$ and $\\tilde{f}_1 = \\tilde{\\omega}_n$.

Indeed, we know that $\\omega_m = f_0$ has a lift, namely $\\tilde{\\omega}_m$ as defined in proof of homomorphism of $\\Phi$. But Lemma \\ref{lemma: SpCase Path} tells us that the given lift $\\tilde{f}_t$ of $f_t$ is unique. So if $\\tilde{f}_0$ is any other lift of $f_0 = \\omega_m$, it must be that $\\tilde{f}_0 = \\tilde{\\omega}_m$. A similar statement holds for the two lifts $\\tilde{f}_1$ and $\\tilde{\\omega}_n$ of $\\omega_n = f_1$.

Since $\\tilde{f}_t$ is a path homotopy, $\\tilde{f}_t(1)$ (the shared endpoint of the loops that $\\tilde{f}_t$ is ``homotopy-ing") must be constant for all $t$. In particular, we must have    
$\\tilde{f}_t(1) = \\tilde{\\omega}_m(1) = \\tilde{\\omega}_n(1)$, the common endpoint of $\\tilde{\\omega}_m$ and $\\tilde{\\omega}_n$.

But this common endpoint must be an integer (again due to the map $p$, which gives $(1,0)$ as output iff $s \\in \\ZZ$, and it must be both $m$ and $n$! Hence $m = n$. Thus we finally conclude that $\\Phi$ is a group isomorphism, i.e. $\\pi_1(S^1) \\cong \\ZZ$.

\\end{proposition}

By compactness of $\\{y_0\\} \\times I$ (since it's homeomorphic to $I$), finitely many such products $N_t \\times (a_t, b_t)$ cover $y_0 \\times I$. Thus we can choose a single neighborhood $N$ of $y_0$ and a partition $0 = t_0 < t_1 < \\dots < t_m = 1$ of $I$ so that for each $i$, $F(N \\times [t_i, t_{i+1}])$ is contained in $U_\\alpha$ for some $\\alpha$, which we'll now denote by $U_i$.

Our present goal is to construct a lift $G: N \\times I \\to \\mathbb{R}$ where $N \\times I$ is the "rainbow tube." Assume by induction on $i$ that $G$ has already been constructed on $N \\times [0, t_i]$. (This is true for $i = 0$ since $N \\times \\{0\\}$ is a subset of $Y \\times \\{0\\}$ and by assumption, we already have the map $\\tilde{F}: Y \\times \\{0\\} \\to \\mathbb{R}$.) Now since $F(N \\times [t_i, t_{i+1}]) \\subset U_i$, we know by our Observation that $p^{-1}(U_i)$ is a disjoint union of open sets in $\\mathbb{R}$, each of which is mapped homeomorphically onto $U_i$. Hence there exists a $\\tilde{U}_i \\subset p^{-1}(U_i)$ that contains the point $G(y_0, t_i)$ (this point exists by the induction hypothesis) since $(y_0, t_i)$ sits inside $N \\times [0, t_i]$, and the latter maps into $U_i$ by $F$.

Now it's possible that $G(N \\times \\{t_i\\})$ (the lift of the top slice of $N \\times [0, t_i]$) isn't fully contained within $\\tilde{U}_i$ but we can assume it is. Finally, we may define $G$ on $N \\times [t_i, t_{i+1}]$ by  
\\[
(p|_{\\tilde{U}_i})^{-1} \\circ F|_{[t_i, t_{i+1}]}.
\\]
(This is exactly what you think it should be! Imagine for a moment that $N \\times [t_i, t_{i+1}]$ is the green rectangle in our "rainbow tube" above. We can map it to $\\mathbb{R}$ by first mapping it across to $S^1$ via $F$ and then lifting it up to $\\tilde{U}_i$ via $p^{-1}$.)

This is well-defined since $p|_{\\tilde{U}_i}$ is a homeomorphism, so we can repeat this inductive step finitely many times to obtain the desired lift $G: N \\times I \\to \\mathbb{R}$ for some neighborhood $N$ of $y_0$. And since $y_0 \\in Y$ was arbitrary, we have our lift $G$ on all of $Y \\times I$.
\\end{proof}
